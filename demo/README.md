# Demo

`full_demo.mp4` — complete demonstration of the running system:

1. **Real-time mapping on TUM-RGBD** at native speed, with the per-primitive confidence field visualized live (blue: low, red: high).
2. **On-robot runs** on a wheeled platform (all computation onboard an RTX 3090): live camera feed alongside the incrementally growing Gaussian field.
3. **Loop correction** before/after comparisons on long-term sequences.

The same recording is embedded on the [project page](https://anoymous-code.github.io/muSLAM/) for in-browser playback.
