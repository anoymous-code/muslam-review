# Demo

`full_demo.mp4` — demonstration of the running system:

1. **Real-time mapping on TUM-RGBD** at native speed.
2. **On-robot runs** on a wheeled platform (all computation onboard an RTX 3090): live camera feed alongside the incrementally growing photorealistic Gaussian map.

The same recording is embedded on the [project page](https://anoymous-code.github.io/muSLAM/) for in-browser playback. Per-primitive confidence visualizations and loop-correction results are illustrated in the manuscript (Fig. 1 and Fig. 7).
